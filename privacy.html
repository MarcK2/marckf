Privacy Policy

Last updated: November 15, 2026

This policy describes how the MarcKFragrance publishing tool (the "Tool") handles data. The Tool is an internal application used only by the owner of the MarcKFragrance YouTube channel to upload videos to that channel. It uses YouTube API Services.

YouTube API Services

The Tool uses YouTube API Services. By using the Tool, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data accessed

With the channel owner's authorization (OAuth), the Tool accesses only:

  • the owner's own YouTube channel, to upload videos and set their titles, descriptions, tags, privacy status, scheduled publication time and content disclosures;
  • the subtitle tracks of those videos, to add English, French and Spanish subtitles;
  • basic channel information (channel name and identifier), to confirm the destination channel before an upload.

The Tool does not access viewers' data, comments, messages, analytics of other channels or any other Google account.

Use and storage

The data above is used only to publish the channel's own videos. The authorization token is stored locally on the channel owner's computer or private server, in an environment file that is never shared or published. Video files and their publication records are stored in the same private environment.

Sharing

No data obtained through YouTube API Services is sold, shared with or disclosed to third parties.

Revoking access

Access can be revoked at any time from the Google account security settings: Google security settings > Third-party apps with account access. Locally stored tokens are then deleted.
